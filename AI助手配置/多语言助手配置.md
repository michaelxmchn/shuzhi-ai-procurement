## 四、定制需求询问流程

### 4.1 通用流程图

```
客户进入网站
     ↓
选择语言（自动匹配助手语言版本）
     ↓
全能助手接待
     ↓
判断是否需要专业助手
     ↓
转接对应行业的专业助手
     ↓
┌─────────────────────────────────────────┐
│           专业助手对话流程              │
├─────────────────────────────────────────┤
│ 1. 开场：直接问产品                    │
│    "您好！要什么型号？"                │
│                                         │
│ 2. 追问：数量/规格/交期               │
│    "多少量？什么交期？"                │
│                                         │
│ 3. 定制需求询问                        │
│    "定制还是现货？"                    │
│    ↓                                    │
│    ┌──────────────┬──────────────┐     │
│    │ 客户说定制   │ 客户说不知道  │     │
│    └──────────────┴──────────────┘     │
│          ↓                  ↓          │
│    追问：材质/    进入需求分析模式     │
│    数量/交期                         │
│                                         │
│ 4. 需求分析（客户不知道要什么）        │
│    - 了解用途                         │
│    - 了解预算                         │
│    - 了解数量                         │
│    - 了解渠道                         │
│    - 推荐方案                         │
│                                         │
│ 5. 收尾确认                          │
│    "好，我给您报价"                   │
└─────────────────────────────────────────┘
```

### 4.2 定制需求判断关键词

| 关键词 | 意图 | 助手响应 |
|--------|------|----------|
| 定制 | 定制需求 | 追问：材质？数量？交期？ |
| OEM | 代工需求 | 追问：设计图？数量？ |
| ODM | 设计生产 | 追问：功能需求？ |
| 没有要求 | 迷茫客户 | 引导需求分析 |
| 不知道 | 迷茫客户 | 引导需求分析 |
| 你推荐 | 需要推荐 | 进入推荐模式 |

### 4.3 需求分析模式话术

```
客户：不知道要什么 / 你推荐

Step 1: 了解用途
助手：您采购这个是做什么用的？
客户：用在XXX产品上

Step 2: 了解预算
助手：您的预算大概是多少？
客户：XXX元左右

Step 3: 了解数量
助手：这次大概要多少量？
客户：XXX个

Step 4: 了解偏好
助手：对品牌有要求吗？还是要性价比？
客户：品牌/性价比

Step 5: 推荐方案
助手：根据您的情况，我推荐以下方案：
方案A：XXX（详细说明）
方案B：XXX（详细说明）
方案C：XXX（详细说明）
```

## 六、网站语言自动匹配

### 6.1 前端实现

```javascript
// 语言到助手目录的映射
const languageMap = {
    'zh-CN': 'zh-CN',
    'zh': 'zh-CN',
    'en': 'en',
    'pt': 'pt',
    'pt-BR': 'pt',
    'es': 'es',
    'es-LA': 'es',
    'ar': 'ar',
    'ja': 'ja',
    'ko': 'ko'
};

// 获取对应助手目录
function getAssistantPath(industry, language) {
    const lang = languageMap[language] || 'en';
    return `/assistants/${industry}/${lang}/`;
}
```

### 6.2 后端实现

```python
# 根据用户语言选择助手版本
def get_assistant_version(industry: str, language: str) -> str:
    language_map = {
        'zh-CN': 'zh-CN',
        'zh': 'zh-CN', 
        'en': 'en',
        'pt': 'pt',
        'pt-BR': 'pt',
        'es': 'es',
        'es-LA': 'es',
        'ar': 'ar',
        'ja': 'ja',
        'ko': 'ko'
    }
    
    lang = language_map.get(language, 'en')
    return f"assistants/{industry}/{lang}/"
```
